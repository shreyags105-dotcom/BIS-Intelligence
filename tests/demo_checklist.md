# Demo Checklist

## Final demo scenario

> “I want to manufacture a pressure cooker. What BIS standard applies, what are the requirements and tests, and how do I get certification?”

## Checklist

### Industry scenario

- [ ] User asks about manufacturing a pressure cooker
- [ ] Assistant identifies the product
- [ ] Applicable standard appears: IS 2347
- [ ] Requirements are shown clearly
- [ ] Testing requirements are displayed
- [ ] Certification guidance is displayed
- [ ] Official BIS source/reference is shown

### Consumer scenario

- [ ] User asks about BIS mark or BIS consumer guidance
- [ ] System gives a simple explanation
- [ ] Source/reference is visible

### Service scenario

- [ ] User asks about hallmarking
- [ ] User asks about testing laboratory guidance
- [ ] Responses are BIS-focused and source-backed

### Safety / reliability checks

- [ ] Unsupported questions are handled safely
- [ ] Fake or impossible standards are rejected without inventing information
- [ ] The assistant clearly states when BIS information is unavailable

### Presentation readiness

- [ ] App is running
- [ ] Backend is active
- [ ] Test validation is already done
- [ ] Demo flow is rehearsed
- [ ] PS coverage checklist is ready

## Final outcome

The demo should clearly show that the project can recommend standards, explain certification and testing requirements, support consumer understanding, and stay grounded in BIS information.
